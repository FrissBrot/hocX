# Schriften der Dokument-Engine

Mitgeliefert, damit Dev, CI und Produktion identisch rendern (der Typst-Compile nutzt keine
Systemschriften). Alle Schriften stehen unter der SIL Open Font License 1.1; die
Lizenztexte liegen jeweils daneben.

| Familie | Dateien | Quelle | Lizenz |
|---|---|---|---|
| Inter 4.1 | `Inter-*.ttf` | github.com/rsms/inter | `LICENSE-Inter.txt` (OFL 1.1) |
| Liberation Sans/Serif 2.1.5 | `LiberationSans-*.ttf`, `LiberationSerif-*.ttf` | github.com/liberationfonts | `LICENSE-Liberation.txt` (OFL 1.1) |
| Noto Sans 2.015 | `NotoSans-*.ttf` | github.com/notofonts/latin-greek-cyrillic | `LICENSE-NotoSans.txt` (OFL 1.1) |
| Noto Color Emoji 2.051 | `NotoColorEmoji.ttf` (CBDT) | github.com/googlefonts/noto-emoji | `LICENSE-NotoColorEmoji.txt` (OFL 1.1) |

Noto Sans und Noto Color Emoji sind Fallbacks für Zeichen, die die Hausschrift nicht hat.
Typst bringt zusätzlich DejaVu Sans Mono (Code) mit.
