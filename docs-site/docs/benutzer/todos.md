# Todos

Aufgaben (`Todos`), die aus einem Protokoll heraus entstehen, lassen sich zentral unter
*Todos* verfolgen (Status offen/erledigt) und im Protokoll wieder darstellen –
Todo-Blöcke können sich analog zu Terminen auch "pro Todo" wiederholen.

## Notizen und Dateien

Ein Klick auf ein Todo in der Todo-Liste öffnet das Bearbeiten-Popup. Dort gibt es:

- **Notizen**: freier Text mit demselben Editor wie im Protokoll (fett, kursiv, Aufzählungen,
  nummerierte Listen). Markdown wird direkt formatiert angezeigt.
- **Dateien**: über das Suchfeld lassen sich bereits hochgeladene Dateien (Dateien- und
  Fotos-Seite) mit dem Todo verknüpfen. Ein Klick auf eine Datei öffnet sie, das ✕ entfernt nur die
  Verknüpfung, nicht die Datei.

Änderungen werden mit «Speichern» übernommen. Notizen und Dateien sind nur in diesem Popup
sichtbar, nicht in der Liste, der Übersicht, im Protokoll oder in Exporten.
