# Listen

Frei konfigurierbare, strukturierte Listen (`Lists`) für vereinsspezifische Daten, z. B.
eine Vorstandsliste mit Namen/Funktion, oder eine Inventarliste.

Eine Liste kann in Vorlagen auf zwei Arten eingebunden werden:

- **Ganze Liste gekoppelt** – die komplette Liste erscheint live als Tabelle im
  Protokoll, Änderungen an der Liste wirken sich sofort aus.
- **Einzelne Zeile aus Liste** – eine einzelne Tabellenzeile in einer Vorlage wird fest
  mit einem Listeneintrag verknüpft. Pro Spalte lässt sich wählen, ob sie "fix"
  (übernimmt den Wert aus der Liste, mit optionalem Alias-Text) oder "variabel" (im
  Protokoll frei editierbar) ist.

In beiden Fällen bleibt die Verknüpfung **live**, solange das Protokoll nicht
abgeschlossen ist.
