# Erste Schritte

## Anmelden

Jeder Verein (Mandant) hat einen eigenen Zugang. Die Anmeldung erfolgt unter `/login`
mit E-Mail-Adresse und Passwort. Ist ein Benutzer Mitglied mehrerer Vereine, kann er
nach dem Login zwischen den Mandanten wechseln.

## Typischer Ablauf

1. **Vorlage prüfen/anlegen** – unter *Vorlagen* wird der Aufbau einer wiederkehrenden
   Sitzungsart (z. B. "Vorstandssitzung") definiert: Elemente (Traktanden) und darin
   verschachtelte Blöcke (Text, Tabelle, Matrix, Terminliste, Bilder, Todos …).
2. **Zyklus festlegen** – ein Zyklus bündelt eine Vereinsperiode/-jahr und liefert u. a.
   Platzhalter wie das Startjahr für Titel/Elemente.
3. **Protokoll erstellen** – aus einer Vorlage plus Zyklus entsteht ein neues, zunächst
   im Status *geplant* befindliches Protokoll.
4. **Protokoll füllen** – im Status *geplant* werden Struktur-/Auswahldaten über kleine
   Icons und Popups gepflegt (Termine zuordnen, Listenzeilen wählen, Teilnehmer
   auswählen). Nach der Sitzung wechselt das Protokoll auf *durchgeführt*, danach ist
   Inline-Nachbearbeitung möglich.
5. **Abschliessen** – ein abgeschlossenes Protokoll ist unveränderlich (Snapshot) und
   kann als PDF exportiert werden.

## Wichtig: Snapshot-Prinzip

Ein Protokoll ist eine **eigenständige Kopie** der Vorlage zum Zeitpunkt seiner
Erstellung. Ändert man später die Vorlage, wirkt sich das **nicht** auf bereits
erstellte Protokolle aus – so bleibt die Historie konsistent, auch wenn sich der Ablauf
künftiger Sitzungen ändert.
